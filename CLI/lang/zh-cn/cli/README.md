# QuickBox Pro - 模块化语言系统

## 概述

此目录包含 QuickBox Pro CLI 的模块化语言系统。原始的 `cli_lang` 文件（3,695 行）已被拆分为功能模块，以便更好地组织、维护和扩展。

## 模块结构

模块化语言系统按以下功能组进行组织：

### 核心模块
- **core.sh** - 核心系统操作（锁、清理、基本函数）
- **apt.sh** - APT 包管理操作
- **software.sh** - 软件安装、移除和更新操作
- **ssl.sh** - SSL/LetsEncrypt 证书管理
- **dns.sh** - DNS 凭据管理
- **users.sh** - 用户管理操作
- **vpn.sh** - VPN/WireGuard 操作
- **database.sh** - 数据库管理（MySQL/SQLite）
- **updater.sh** - 系统更新器操作
- **manager.sh** - 软件管理器（备份/恢复/回滚）
- **help.sh** - 帮助消息和错误处理

### 扩展模块
- **software_access.sh** - 软件访问信息和 URL
- **software_config.sh** - 软件配置和设置消息
- **wireguard.sh** - WireGuard 特定配置和管理
- **misc.sh** - 杂项实用工具和通用系统消息

## 模块描述

### 核心模块

#### core.sh
包含核心系统操作，包括：
- 内存和缓存清理函数
- 锁处理和移除
- 仪表板日志记录实用工具
- 基本系统状态消息

#### apt.sh
管理 APT 包管理操作：
- 包数据库更新
- 锁解析
- 升级完成消息
- 包检查和验证

#### software.sh
处理软件安装、移除和更新：
- 安装标题和进度
- 重新安装过程
- 移除操作
- 更新程序
- 构建和依赖管理

#### ssl.sh
全面的 SSL/LetsEncrypt 证书管理：
- 证书安装和续期
- 多个提供商的 DNS 挑战支持
- HTTP 挑战操作
- 证书验证和错误处理
- 各种提供商的交互式 DNS 设置

#### dns.sh
DNS 凭据管理系统：
- 提供商状态检查
- 凭据验证
- 所有支持提供商的设置说明
- 错误处理和故障排除
- 备份和恢复操作

#### users.sh
用户管理操作：
- 用户创建和删除
- 密码管理
- 用户提升和降级
- 封禁/解封操作

#### vpn.sh
VPN 和 WireGuard 操作：
- VPN 配置
- 客户端设置
- 服务器管理
- 连接状态

#### database.sh
MySQL 和 SQLite 的数据库管理：
- 安装和配置
- 数据库类型之间的迁移
- 备份和恢复操作
- 维护和优化
- 完整性检查

#### updater.sh
系统更新器操作：
- 更新进度跟踪
- 依赖管理
- 组件更新
- 完成状态

#### manager.sh
软件管理器操作：
- 备份创建和管理
- 恢复操作
- 回滚功能
- 默认配置管理
- 版本管理

#### help.sh
帮助系统和错误处理：
- 软件特定帮助生成
- 命令使用说明
- 错误消息和警告
- 交互式帮助函数

### 扩展模块

#### software_access.sh
软件访问信息和配置：
- Web 界面 URL 和端口
- 访问凭据和设置
- 域名特定访问信息
- 客户端配置详情

#### software_config.sh
软件配置和特殊处理：
- Ombi 的 MySQL 迁移

#### wireguard.sh
WireGuard 特定操作：
- 客户端和服务器配置
- 交互式设置过程

#### misc.sh
杂项实用工具和通用消息：
- 未知选项处理
- 通用错误消息
- 实用函数
- NordVPN 配置生成器帮助

## 使用方法

### 对于开发者

1. **添加新消息**：根据功能将新的语言函数添加到适当的模块
2. **修改现有消息**：在相关模块中定位函数并更新它
3. **创建新模块**：遵循现有模块的命名约定和结构

### 对于系统管理员

1. **使用模块化系统**：系统通过 `cli_lang_modular` 自动加载所有模块
2. **向后兼容性**：所有现有函数调用继续无变化地工作
3. **模块验证**：系统验证所有必需模块都存在

## 命名约定

- **文件名**：使用描述性名称，扩展名为 `.sh`（例如：`software_access.sh`）
- **函数名**：遵循 `quickbox::lang::category::subcategory::action()` 模式
- **变量**：使用描述性名称和适当的作用域
- **注释**：为复杂函数包含全面的文档

## 优势

### 可维护性
- **专注模块**：每个模块处理特定的功能区域
- **更容易导航**：开发者可以快速定位相关函数
- **降低复杂性**：较小的文件更容易理解和修改

### 可扩展性
- **模块化增长**：可以添加新功能而不影响现有模块
- **独立开发**：多个开发者可以同时处理不同的模块

### 组织性
- **逻辑分组**：相关函数被分组在一起
- **清晰结构**：模块层次结构反映系统架构
- **文档**：每个模块都有明确的目的，具有自文档化功能
